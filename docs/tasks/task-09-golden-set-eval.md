# task-09: 골든셋 품질 평가

- 브랜치: `chore/golden-set-eval`
- 커밋 타입: `chore:`
- 선행 조건: task-07 머지 (task-08과 병렬 가능)

## 배경

"AI 도우미가 잘 동작한다"를 주장이 아닌 측정으로 만든다. law-404에서 쓴 골든셋 방식을 재사용한 축소판.

## 작업 단계

1. `ai-service/eval/golden/` 에 케이스 12개 작성 — 실물 사진 URL + 기대값(정답 카테고리, 가격 허용 범위, 필수 키워드). 카테고리 분포: 주요 카테고리당 최소 1개 + 애매한 경계 케이스 2개(예: 풋살화 vs 축구화) + 저품질 사진 1개
2. 평가 스크립트 `ai-service/eval/run_eval.py`: 전 케이스 실행 → 카테고리 정확도, 가격 범위 적중률, 제목/설명 형식 준수율 출력, 결과 json 저장
3. 1회 실행 결과를 `docs/measurements/ai-quality-baseline.md`에 기록 (수치 + 실패 케이스 분석 2~3줄)
4. README에 실행법 기록 (API 비용 주의 명시 — CI 실행 금지)

## 하지 말 것

- 결과가 낮다고 프롬프트 튜닝 착수 금지 — 이 작업은 기준선 측정만. 개선은 별도 작업으로 분리
- 골든셋 케이스를 통과하기 쉽게 수정하는 것 금지
- CI에 평가 실행 추가 금지 (API 비용)
